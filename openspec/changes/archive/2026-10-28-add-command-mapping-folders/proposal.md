# Proposal

## Why

当前“命令映射”以单层列表展示和管理，随着 `/openspec-propose` 命令映射数量增长，用户难以按项目、主题或工作流快速定位映射。引入可命名、可无限嵌套的文件夹树，可以在不改变命令调用方式的前提下整理大量映射。

## What Changes

- 为命令映射增加树状文件夹模型，支持文件夹包含子文件夹和命令映射。
- 支持创建、重命名、移动和删除文件夹，并允许文件夹单独命名。
- 在设置界面以可展开/折叠的树展示文件夹和映射，支持在指定文件夹下新增映射。
- 保留现有命令映射的命令名唯一性、启用状态、编辑和删除能力。
- 删除非空文件夹时提供保护或明确的迁移/删除确认，避免误删映射。
- 现有无文件夹的命令映射继续可用，并在升级时归入根层级。

## Capabilities

### New Capabilities

- `command-mapping-folders`: 管理可嵌套、可命名的命令映射文件夹树，以及映射在树中的归属和移动。

### Modified Capabilities

- 无。

## Impact

- 配置模型及迁移逻辑：为文件夹节点增加稳定 ID、名称、父节点关系，并为映射保存所属文件夹。
- 命令映射 IPC/API：增加文件夹 CRUD、移动映射及树形读取能力；现有映射 CRUD 需要兼容 folderId。
- 设置界面：重构命令映射区域的列表为树状浏览与管理交互。
- 命令注册和解析：命令解析仍按命令名工作，不受文件夹层级影响。
- 测试与持久化兼容性：覆盖嵌套、重命名、移动、删除保护、重复名称及旧配置升级场景。
