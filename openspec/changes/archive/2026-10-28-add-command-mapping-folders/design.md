# Design

## Context

See `proposal.md` for motivation and `specs/command-mapping-folders/spec.md` for the externally visible contract. 当前配置以 `aliases` 数组保存映射，Zod schema 在加载和保存时校验；设置页通过现有 settings IPC 对映射执行 CRUD，命令注册表只关心启用映射的全局命令名。该功能需要同时扩展持久化、迁移、IPC 和 Vue 设置界面，但不应把文件夹路径带入命令解析协议。

## Goals / Non-Goals

**Goals:**

- 用稳定 ID 和父子关系表达任意深度的文件夹树。
- 让映射保存可为空的 `folderId`，并通过统一树读取模型驱动设置页。
- 保持命令解析、冲突检测和全局命令名唯一性的现有语义。
- 为旧配置提供无损升级和对损坏层级数据的可恢复策略。
- 让文件夹操作具备服务端校验，避免仅依赖渲染器状态。

**Non-Goals:**

- 不改变 `/openspec-propose` 命令的语法、快捷键或运行时查找优先级。
- 不引入云同步、跨设备共享或多用户权限。
- 不支持同一映射同时属于多个文件夹。
- 不在本次变更中增加标签、搜索或拖拽排序等独立组织方式。

## Decisions

### 1. 使用扁平节点集合表达树

新增 `folders` 集合，每个节点包含 `id`、`name` 和可为空的 `parentId`；映射增加可为空的 `folderId`。读取时在边界层组装树，写入时以 ID 引用保存。这样能稳定处理重命名和移动，避免把整棵嵌套 JSON 作为更新单元；也比单纯保存路径更能避免路径重命名导致映射失联。

替代方案：直接嵌套 folders 数组。该方案读取直观，但移动、引用校验、旧数据修复和局部更新更复杂，因此不采用。

### 2. 文件夹名称只要求同级唯一

文件夹名称在同一父节点下大小写不敏感地唯一，允许不同分支使用相同名称；文件夹与映射命令名不共享命名空间。这样既避免同一列表中歧义，也允许按不同项目复用常见分类名。

### 3. 删除采用服务端安全策略

删除接口默认只允许删除空文件夹；对非空文件夹提供显式的“将内容移动到父层级后删除”操作（或等价的确认参数），服务端在一次配置更新中完成移动和删除。禁止隐式级联删除，避免 UI 误操作造成数据丢失。

### 4. 兼容迁移优先于版本破坏

配置版本仍通过现有迁移机制递增。缺少 `folders` 时使用空集合，旧映射的 `folderId` 视为根；无效或循环的 folder 引用在 salvage 阶段降级到根并产生警告。命令注册表继续消费扁平 aliases，不依赖 folders。

### 5. 树 UI 与操作 API 分离

settings IPC 提供完整树快照和 folder/mapping 操作结果；Vue 组件只负责展开状态、选中状态、表单和反馈。这样可让主进程成为校验和持久化的单一事实来源，并使渲染器刷新后不会保留幽灵节点。

## Risks / Trade-offs

- [配置结构升级可能触发部分恢复] → 为迁移、salvage、重复 ID、循环 parentId 和未知 folderId 增加测试，并在设置页显示已有警告机制。
- [树深度过大导致 UI 缩进或渲染压力] → 使用递归树组件但限制单次展开渲染范围，保持默认折叠深层节点；命令查找仍为 O(1) 映射查找。
- [同级名称的大小写规则与旧命令规则不同] → 在共享 schema/服务校验中统一使用大小写不敏感比较，并为重命名和创建返回明确错误。
- [删除非空文件夹的用户决策增加交互复杂度] → 首版采用“移动内容后删除”的单一安全路径，接口拒绝未确认的非空删除。
- [现有 IPC 类型变更影响调用方] → 保留现有 alias CRUD 字段的向后兼容默认值，仅新增可选 folderId，并同步更新 preload 类型与主进程校验。

## Migration Plan

1. 扩展配置 schema、迁移和 salvage 逻辑；先确保旧配置加载结果与现有命令行为一致。
2. 增加主进程 folder 服务和 IPC handler，再接入现有映射 CRUD 的 folderId。
3. 将设置页列表替换为树视图，逐步接入创建、重命名、移动和安全删除。
4. 运行迁移、服务、IPC、组件和回归测试；发现问题时可回滚应用代码，已写入的新增字段由兼容读取逻辑保留在配置中，不影响旧版本读取根层映射。

## Open Questions

无。规范已确定首版的根层级、同级名称唯一性、全局命令唯一性及非空文件夹删除策略。
