# Proposal

## Why

现在整个桌面 UI 是「一页长滚动 + 四张卡片」：命令映射、插件、快捷键、浏览器连接混排在同一条滚动流里，高频操作（管理映射与脚本）和低频配置（快捷键、扩展配对）互相干扰，用户要在无关区域之间来回滚动。视觉上每张卡片各写一套间距、圆角、按钮与状态样式，`main.css` 已膨胀到 1184 行且存在重复选择器（`.toggle` / `.tree-toggle`、按钮变体等），交互反馈（保存、toast、页面内跳转）也缺少统一节奏。

把信息拆成两个聚焦页面、集中一套设计令牌、统一动效与反馈通道，可以同时解决「找得到」和「用起来顺」两个问题，且不需要改动 IPC 与主进程业务逻辑。

## What Changes

- **双页面信息架构**：单页长滚动拆为左侧竖向侧栏导航的两个页面——「映射与脚本」（命令映射树 + 脚本/插件管理）与「设置」（快捷键与输入 + 浏览器扩展）。侧栏常驻、当前页高亮、支持 `⌘/Ctrl+1/2` 与方向键切换。
- **自绘无边框标题栏**：macOS 使用 `hiddenInset` + 交通灯留白，Windows 使用系统覆盖按钮（WCO），顶栏区作为窗口拖动区，交互元素不拦截拖动；非 macOS/Windows 回退原生边框。
- **设计令牌层**：颜色、间距、圆角、字号、阴影、动效时长/缓动集中为 tokens，把 `assets/main.css` 拆成 `tokens` / `shell` / `components` 三层，组件内不再硬编码颜色与缓动。
- **动效与状态保持**：页面切换（方向感淡入 + 位移，≤240ms）、侧栏指示条滑动、hover/press/focus 节奏统一、toast 进出场；`prefers-reduced-motion: reduce` 时取消位移与缩放。切换页面保留滚动位置、树展开状态、未保存表单与录制中的快捷键。
- **交互一致性**：插入方式、登录启动改为「变更即保存」（乐观更新 + 失败回滚 + toast），快捷键保留「录制 → 应用」两段式；错误统一走 toast 与行内错误双通道。
- **映射页增加客户端过滤**：按命令名/映射文本即时过滤，保留祖先文件夹与原有拖拽、右键、剪切粘贴、启用切换行为。
- **设置页重排**：分组为「快捷键与输入」「浏览器扩展」；首次引导卡片在未完成时显示于设置页顶部，其中「插件目录」步骤提供跳转到映射与脚本页的入口。
- **BREAKING（渲染层内部契约）**：`SettingsApp.vue` 单入口拆分为 shell + 两个 view，DOM 结构与部分类名变化，依赖旧选择器的 DOM 测试需同步调整。托盘菜单「设置」打开窗口后落在设置页。

## Capabilities

### New Capabilities

- `app-shell`: 桌面窗口外壳与双页导航——页面信息架构、自绘标题栏与拖动区、页面切换动效与节奏、动效可访问性降级、跨页面状态保持、全局反馈通道、视觉令牌一致性。

### Modified Capabilities

- `settings`: 设置页结构从「四个平铺区域」改为「快捷键与输入 + 浏览器扩展」两个分组；命令映射与插件管理移到「映射与脚本」页面；插入方式与登录启动改为变更即保存；新增映射过滤行为。

## Impact

- **渲染层**：新增 `src/renderer/src/shell/`（外壳、侧栏、标题栏、导航状态）与 `src/renderer/src/views/`（映射与脚本、设置）；复用并微调 `src/renderer/src/settings/` 下的既有 Section；`assets/` 拆分为 `tokens.css`、`shell.css`、`components.css`；浮层 `overlay/overlay.css` 对齐同一套令牌。
- **主进程**：`src/main/app/windows.ts` 增加 `titleBarStyle` / `titleBarOverlay` / `trafficLightPosition` 等窗口选项；不新增 IPC 通道、不改动命令解析与配置存储。
- **测试**：`tests/dom/settings/*` 需随 DOM 结构调整；新增 shell 导航、状态保持、过滤与「变更即保存」的 DOM 测试；`docs/manual-test.md` 增补两页导航与标题栏的手工验收项。
- **依赖**：不引入 vue-router、动画库或新的运行时依赖。
- **归档顺序依赖**：`settings` 能力的基线规格目前只存在于进行中的变更 `add-quick-input-assistant`（主规格尚未同步），本变更的 `settings` delta 使用 MODIFIED，需要在 `add-quick-input-assistant` 归档/同步之后再归档。

## Out of Scope

- 主题切换（浅色/高对比度）与品牌视觉重做。
- 页内脚本编辑器（脚本仍由外部编辑器编写，页面只做列表、错误、重载与打开目录）。
- 全局命令面板、跨页面搜索、键盘快捷键自定义扩展。
- 浮层窗口的位置、尺寸与焦点策略改造。
