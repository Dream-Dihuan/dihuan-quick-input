# Spec Delta

## Purpose

把用户输入的短命令解析为最终文本，并通过静态别名、内置函数和本地插件三层机制提供可扩展、可诊断的命令能力。

## ADDED Requirements

### Requirement: 命令语法解析

系统 SHALL 把输入按空白拆分为命令名和参数：第一个词是命令名，其余部分作为参数；参数支持单引号和双引号以保留空格。命令名匹配 MUST 忽略 ASCII 大小写。输入为空或只有空白时不得解析为命令。

#### Scenario: 无参数命令

- **WHEN** 用户输入 `name`
- **THEN** 系统按命令名 `name` 解析，参数列表为空

#### Scenario: 带参数命令

- **WHEN** 用户输入 `age 19`
- **THEN** 系统按命令名 `age` 解析，参数为 `["19"]`

#### Scenario: 引号保留空格

- **WHEN** 用户输入 `greet "Alice Smith"`
- **THEN** 系统解析出一个参数 `Alice Smith`

#### Scenario: 命令名大小写不敏感

- **WHEN** 用户输入 `NAME`
- **THEN** 系统按 `name` 命令解析

### Requirement: 静态别名

用户 SHALL 能定义“命令名 → 固定文本”的静态别名，例如 `name` → 张三。静态别名 MUST 优先于同名内置函数和插件命令；别名命令不接受参数，传入额外参数时 MUST 返回错误而不是静默忽略。

#### Scenario: 解析静态别名

- **WHEN** 用户配置了 `name` → 张三并输入 `name`
- **THEN** 系统返回文本 `张三`

#### Scenario: 别名收到额外参数

- **WHEN** 用户配置了 `name` → 张三并输入 `name extra`
- **THEN** 系统返回“该命令不接受参数”的错误且不插入文本

### Requirement: 内置函数命令

系统 SHALL 提供一组可带参数的内置函数命令，至少覆盖年龄文案、当前日期、当前时间、UUID 和大小写转换。内置函数 MUST 校验参数数量与格式，格式错误时返回可理解的错误而不是生成异常文本。

#### Scenario: 年龄命令

- **WHEN** 用户输入 `age 19`
- **THEN** 系统返回 `19 岁`

#### Scenario: 年龄参数非法

- **WHEN** 用户输入 `age abc`
- **THEN** 系统返回参数错误且不插入文本

#### Scenario: 日期与 UUID

- **WHEN** 用户分别输入 `date` 和 `uuid`
- **THEN** `date` 返回本地日期文本，`uuid` 返回一个 UUID 文本

### Requirement: 本地插件命令

系统 SHALL 从本地插件目录加载插件命令。插件中的每个命令对应一个接收参数与执行上下文的函数，并同步返回字符串；用户可以在不重启应用的情况下重新加载插件。单个插件加载失败 MUST 只影响该插件，其他命令仍可使用。

#### Scenario: 插件命令可用

- **WHEN** 插件导出了 `company` 命令并返回固定文本，用户输入 `company`
- **THEN** 系统返回该插件提供的文本

#### Scenario: 重新加载插件

- **WHEN** 用户修改插件文件后在设置页点击重新加载
- **THEN** 新命令或修改后的返回值立即生效，无需重启应用

#### Scenario: 插件语法错误

- **WHEN** 某个插件文件存在语法错误
- **THEN** 设置页显示该插件的错误，其他插件和内置命令继续可用

### Requirement: 插件执行隔离与限制

插件函数 MUST 在受限沙箱中执行，不能访问文件系统、网络、进程或子进程；同步执行超过时间限制或抛出异常时，系统 MUST 终止该次解析并返回错误，不得导致应用崩溃或卡死。

#### Scenario: 插件尝试访问文件系统

- **WHEN** 插件函数尝试调用文件系统 API
- **THEN** 该命令返回“插件不可用”一类错误，应用继续运行

#### Scenario: 插件陷入死循环

- **WHEN** 插件函数执行时间超过限制
- **THEN** 系统终止该次执行并返回超时错误

### Requirement: 命令优先级与冲突

命令解析优先级 MUST 为：静态别名 > 插件命令 > 内置函数。多个插件定义同名命令或命令名与内置函数冲突时，设置页 MUST 显示冲突信息，解析结果必须稳定且可预测。

#### Scenario: 别名覆盖插件与内置函数

- **WHEN** 别名、插件和内置函数都定义了 `age`
- **THEN** 输入 `age` 使用静态别名的结果

#### Scenario: 插件覆盖内置函数

- **WHEN** 没有同名别名，插件与内置函数都定义了 `age`
- **THEN** 输入 `age` 使用插件的结果

### Requirement: 命令错误处理

命令不存在、参数缺失或非法、插件抛错、返回非字符串、返回空字符串或超时时，系统 MUST 返回用户可理解的错误并且不向浏览器插入任何文本。插件返回 Promise 或其他异步结果时 MUST 按不支持处理并返回错误。

#### Scenario: 未知命令

- **WHEN** 用户输入 `unknown-command`
- **THEN** 系统返回命令不存在错误，不插入文本

#### Scenario: 插件返回非字符串

- **WHEN** 插件命令返回数字 `19`
- **THEN** 系统返回“命令必须返回文本”的错误，不插入文本

#### Scenario: 插件返回异步结果

- **WHEN** 插件命令返回 Promise
- **THEN** 系统返回“不支持异步命令”的错误，不插入文本
