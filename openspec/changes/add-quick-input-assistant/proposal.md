# Proposal

## Why

日常在网页表单中反复填写姓名、邮箱、地址等信息既慢又容易出错，频繁复制粘贴也会打断当前工作。现有仓库只有 Electron + Vue 的空白脚手架，适合直接构建一个常驻桌面、全局快捷键唤起的快速输入工具：用户输入简短命令，工具解析出文本并自动写入浏览器当前聚焦的表单控件。

## What Changes

- 新增常驻桌面的 Electron + Vue 应用：通过可配置的全局快捷键唤起轻量输入浮层，输入命令后按回车将解析结果发送给浏览器扩展。
- 新增 Chromium Manifest V3 浏览器扩展（Chrome / Edge）：与桌面应用建立本地连接，记录当前标签页及 iframe 中最后聚焦的可编辑字段，接收文本后直接写入，并兼容 React / Vue 等受控表单。
- 新增命令引擎：支持静态别名（如 `name` → 张三）、带参数的内置函数命令（如 `age 19`）以及本地 JS 插件命令；插件在受限沙箱中同步执行，可在设置页重载并查看错误。
- 新增设置页面：快捷键录制与冲突校验、别名增删改、插入模式、插件目录与重载、扩展配对 token 与连接状态、开机启动等。
- 新增桌面生命周期：单实例运行、托盘常驻、关闭设置窗口后继续运行、可选登录时启动。
- 桌面应用与扩展通过仅绑定 `127.0.0.1` 的 WebSocket + 配对令牌通信；扩展断线后自动重连，无法连接或字段失效时向用户明确反馈，不静默失败。
- **范围边界**：v1 仅支持 macOS 与 Windows 桌面，以及 Chrome / Edge 浏览器；Firefox、Safari、Linux、云同步、浏览器商店正式发布不在本次变更范围内。

## Capabilities

### New Capabilities

- `quick-input-overlay`: 全局快捷键注册、输入浮层的唤起/隐藏/聚焦、命令提交与取消、中文输入法处理、插入结果反馈。
- `command-engine`: 命令语法解析、静态别名、内置函数、本地 JS 插件加载与沙箱、命令优先级和错误处理。
- `browser-insertion`: 扩展配对与本地连接、焦点字段跟踪、文本写入语义、iframe 支持、断线重连和失败上报。
- `settings`: 设置窗口结构、快捷键配置、别名管理、插件管理、插入模式、连接状态展示、配置持久化与校验。
- `app-lifecycle`: 单实例、托盘常驻、窗口关闭行为、开机启动和设置入口。

### Modified Capabilities

无。当前项目尚无已归档的 `openspec/specs/` 能力。

## Impact

- **代码**：扩展 `src/main`（窗口、托盘、快捷键、配置、命令引擎、WebSocket 服务）、`src/preload`（类型化 IPC）、`src/renderer`（设置页与浮层两个入口）、新增 `src/shared`（协议与共享类型）以及独立的 `extension/` 目录。
- **依赖**：预计新增 `ws`（本地 WebSocket 服务）、`zod`（配置与协议校验）、`vitest`（单元测试）和 `esbuild`（扩展打包）；复用现有 Electron、Vue、TypeScript、electron-vite。
- **构建与分发**：新增扩展构建脚本，输出可加载的 MV3 目录/压缩包；桌面安装包不强制内置扩展，扩展先以开发者模式加载。
- **数据与安全**：配置写入 Electron `userData`；插件从本地插件目录加载；WebSocket 仅监听回环地址并要求配对令牌；不采集页面内容，默认不支持密码输入框。
- **测试**：为命令解析、优先级、插件沙箱、配置校验、协议与 DOM 写入逻辑补充单元测试，并提供浏览器 + 桌面联调的手动验收清单。
