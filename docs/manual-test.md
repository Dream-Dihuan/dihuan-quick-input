## 命令映射文件夹

设置页“命令映射”是一棵可折叠的目录树，支持任意深度命名文件夹。

- **新建**：右键空白处或文件夹 →「新建子文件夹」/「在此新建映射」；顶部按钮作用于当前选中的文件夹。
- **重命名**：双击文件夹名，或右键 →「重命名」，回车保存、Esc 取消。
- **拖拽移动**：把映射或文件夹拖到目标文件夹行、拖到面板底部的根目录区域即可移动；文件夹不能拖进自身或其子文件夹。
- **剪切 / 粘贴**：右键 →「剪切」，再右键目标位置 →「粘贴到此处」；Esc 取消剪切。
- **删除**：右键 →「删除文件夹」会把其中的映射和子文件夹移动到上一级，并弹出确认，不会静默丢数据。
- **启用状态**：映射行右侧胶囊按钮切换启用/停用，停用后命令解析不到。
- **编辑弹窗**：新增或编辑映射都在居中模态框中完成，无需滚动回页面顶部；Esc、点击遮罩或「取消」关闭，保存失败时窗口保持打开并显示错误。

命令解析始终按全局唯一的命令名查找，与文件夹分类无关；旧配置中的映射迁移到根目录（`folderId: null`）。

### 真实 Chrome 快捷输入与焦点回归（2026-10-27）

使用真实 Chrome 156、真实全局快捷键和真实用户配置，在两台显示器环境执行：

- **浮层焦点竞态**：设置窗口可见时，macOS 异步激活可能把键盘焦点交给设置窗口，导致浮层 `visible: true, focused: false`。修复为显示后约 250ms 重试一次聚焦。用户在实际浮层中输入命令成功；设置窗口可见和关闭两种状态均已验证可输入。
- **浏览器失焦**：按快捷键后 Chrome 失去窗口焦点是预期行为。原 Content Script 要求 `document.activeElement` 仍指向目标字段，导致提交返回 `NO_FIELD`。现改为在浏览器失焦时保留最后一个可编辑字段，并在插入前重新聚焦；页面仍有焦点但焦点移到非可编辑控件时清理旧目标。
- **最终端到端**：关闭设置窗口（`app.dock.isVisible() === false`），在 Chrome 打开临时本地测试页 `http://127.0.0.1:8765/`，点击 `input#text`（页面显示“已聚焦：text”），按真实 `Cmd+Shift+Space`，输入 `name` 并按 Enter。用户确认测试页成功写入，浮层隐藏；主进程查询到 `lastPageFocusAt` 有值，`runtime.errors` 为空。
- **窗口状态**：显示/关闭设置后 Dock 状态符合预期；浮层提交成功后 `visible === false`；扩展到桌面端的连接保持为 Chrome / 0.1.0。
- **仍待手测**：Edge、全屏应用上的浮层覆盖、真实中文输入法、复杂富文本编辑器、托盘/退出和登录启动。

## 手工执行步骤

### 1. 启动桌面应用

```bash
pnpm install
pnpm build:extension
pnpm dev
```

预期：设置窗口显示；托盘/菜单栏出现图标；首次启动显示引导。

### 2. 加载扩展并配对

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启开发者模式，加载 `dist-extension`。
3. 复制设置页“浏览器连接”的 token，粘贴到扩展 popup 并保存。
4. 预期：设置页显示“扩展已连接”、浏览器名称、版本和端口。

### 3. 表单矩阵

准备一个本地测试页，包含：

- `input[type=text]`、`textarea`、`contenteditable`
- React/Vue 受控输入框
- 同源 iframe、另一个端口提供的跨域 iframe
- 密码、数字、文件、隐藏、只读、禁用字段
- 两个标签页

逐项执行：

1. 点击字段，按快捷键，输入命令，按 Enter。
2. 检查字段值、`input`/`change` 事件（可在 DevTools 中监听）、光标位置。
3. 切换到另一标签页或无字段页面，再按快捷键提交，确认不会写入旧页面。
4. 在 iframe 内重复，确认顶层页面未被修改。
5. 使用中文输入法输入 `age 19`，在组合中按 Enter，确认不提交；组合结束后再 Enter 应提交。
6. 切换插入模式为“替换整个字段”，重复输入框测试。

### 4. 桌面生命周期

1. 双击启动应用两次，确认只有一个实例。
2. 关闭设置窗口，回浏览器按快捷键，确认浮层仍出现。
3. 从托盘菜单退出，确认进程结束、快捷键失效、扩展显示断开。
4. 开启登录启动，退出登录后重新登录，确认设置窗口不自动弹出、托盘存在。
5. 在多显示器或把光标移到不同显示器后按快捷键，确认浮层出现在光标所在屏幕。
6. 制造配置损坏（备份后写入非法 JSON），重启，确认备份文件、默认配置和设置页提示。

### 5. 构建

```bash
pnpm build:all
pnpm build:mac
```

记录产物路径、版本、签名/公证状态和安装/启动结果。Windows 环境另执行 `pnpm build:win`。
